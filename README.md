# 🎮 Python Mini Games Hub

A Python-based Mini Games Hub that combines multiple interactive games into a single menu-driven application.

## 📌 About the Project

This project is developed using Python and Object-Oriented Programming (OOP) concepts.

The application provides a simple main menu through which users can select and play different mini games.

The project was created to practice Python programming concepts and understand how multiple functionalities can be organized within a single class-based application.

## ▶️ How to Run

### Using Jupyter Notebook

1. Download the repository.
2. Open `Mini_Games_Hub.ipynb` in Jupyter Notebook or JupyterLab.
3. Run the cells in order.
4. Select a game from the main menu.
5. Follow the instructions displayed on the screen.

### Using Python

Run the Python file from the terminal:

`python Mini_Games_Hub.py`
